# Quiz--Game

A simple interactive quiz game built with Python.

Features

- General Knowledge questions
- Mathematics questions
- 15-second timer for each question
- Score calculation
- Percentage calculation
- Performance feedback
- Replay option
- Saves scores to a text file
- Simple and easy-to-use interface

Technologies Used

- Python
- Random module
- Time module
- Colorama

Installation

Install the required Colorama library:

pip install colorama

How to Run

Run the following command:

python quiz_game.py

How to Play

1. Choose a quiz category.
2. Read each question carefully.
3. Enter your answer before the timer ends.
4. Correct answers increase your score.
5. At the end, your score and percentage are displayed.
6. You can choose to play again.
7. Quiz scores are saved in "quiz_scores.txt".
